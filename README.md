# JMA Construction Estimating Portfolio

A black / light-gray / white responsive portfolio website for Jon Matthew Angeles.

## Deploy to Vercel
1. Create a free Vercel account.
2. Create a GitHub repository and upload these files, or use Vercel's import flow.
3. Import the repository into Vercel.
4. Vercel will deploy the site automatically.

## Before publishing
- Replace `your.email@example.com` in `index.html` with your real email.
- Replace the sample project cards with your actual portfolio images/PDF links.
- Review the experience dates and descriptions for accuracy.
- Add your real portfolio links if desired.

No build step is required; this is a simple static HTML/CSS site.
